# R: 팬노트 아이폰 앱 — 앱스토어 등록 안내

윈도우 PC에서는 아이폰 앱(.ipa)을 만들 수 없어서, **Codemagic**(맥을 빌려 주는 클라우드)이 대신 만들고 TestFlight까지 올려 주게 해 두었습니다.
앱 쪽 준비(아이폰 아이콘·개인정보 매니페스트·암호화 신고 면제·아이폰 전용 설정)는 끝났습니다. 설정 파일은 저장소 맨 위의 `codemagic.yaml` 입니다.

사주 행운번호 아이폰판(`D:\android-build\SajuLuckyLotto\아이폰_앱스토어_등록.md`)과 같은 애플 계정·Codemagic 계정을 그대로 씁니다. 애플 가입·API 키·Codemagic 연결·서명 인증서(1~4단계)는 사주 앱 안내서대로 **한 번만** 하면 됩니다.

## 이 앱만 따로 하는 일

1. **앱 ID** — developer.apple.com → Identifiers → + → App IDs → Bundle ID **Explicit** `com.psm.rescenefanbook`
2. **배포 프로필** — Profiles → + → App Store Connect → 위 App ID → 사주 앱 때 만든 인증서 → 이름 `Rescene App Store` → Codemagic에서 **Fetch profiles**
3. **App Store Connect 신규 앱** — 플랫폼 iOS, 번들 ID `com.psm.rescenefanbook`, SKU `rescene-fanbook-ios`, 기본 언어 한국어
4. **Codemagic** — Add application → GitHub → `rescene-fanbook` → codemagic.yaml → Start new build → **R: 팬노트 iOS (TestFlight)**
5. TestFlight로 내 아이폰에 먼저 설치해 확인 → 심사 제출

## 심사 준비물

- 스크린샷: 아이폰 6.9인치(1320×2868) 최소 1장
- 개인정보 처리방침 URL, 지원 URL (누구나 열 수 있는 주소)
- **앱 개인정보 설문**: 게시판에 글을 쓰면 서버(Supabase)에 저장되므로 "사용자 콘텐츠 — 기타 사용자 콘텐츠, 앱 기능, 신원과 연결되지 않음"으로 답합니다
- 판매 국가는 **대한민국만** 권장

## 심사에서 걸릴 수 있는 점

| 심사 기준 | 내용 | 대비 |
|---|---|---|
| 5.2.1 / 5.2.2 지식재산권 | 실제 가수 이름을 쓴 비공식 앱은 **권리자 허락 문서**를 요구받는 경우가 많음. 구글보다 애플이 더 엄격함 | 소속사 허락을 받으면 심사 메모에 첨부. 없으면 앱 이름에서 그룹 이름을 빼고 "비공식 팬 제작 앱"을 분명히 적기 |
| 1.2 사용자 콘텐츠 | 게시판이 있으면 신고·차단·이용약관 동의가 있어야 함 | 신고 기능은 있음. 차단·약관 동의 화면이 필요하면 저에게 말씀하세요 |
| 4.2 최소 기능 | 웹페이지를 감싼 것뿐인 앱은 거절될 수 있음 | 빵 체크·포토카드 수집 같은 앱 안 기능을 심사 메모에 적기 |

## 업데이트할 때

1. `data.json`이나 `src/template.html` 고치고 `build.ps1` 실행
2. `app/config.xml`의 `version="1.0.0"` 올리기 (안드로이드와 같이 씀)
3. 커밋·push → Codemagic에서 Start new build
