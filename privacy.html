1. 받는 정보와 쓰는 곳

회원가입할 때 이메일, 비밀번호, 닉네임만 받아요. 이메일과 비밀번호는 로그인에, 닉네임은 소통창 글에 표시하는 데만 써요. 이름, 전화번호, 주소, 위치 정보는 받지 않아요. 비밀번호는 암호화되어 저장되고 운영자도 볼 수 없어요.

소통창에 쓴 글(상품, 상태, 동네, 매장 이름, 내용, 작성 시각)은 다른 이용자에게 공개돼요. 회원가입을 하지 않아도 앱의 모든 정보를 볼 수 있어요.

2. 보관 기간과 파기

회원 정보는 탈퇴할 때까지 보관하고, 탈퇴하면 계정과 내가 쓴 글을 바로 지워요. 소통창 글은 7일이 지나면 화면에서 보이지 않게 돼요.

3. 맡기는 곳 (처리 위탁·국외 이전)

  • Supabase Inc. (미국): 회원 정보와 소통창 글 보관. 서버는 AWS 서울 리전(ap-northeast-2)에 있어요. 탈퇴할 때까지 보관해요.
  • GitHub Pages (GitHub Inc., 미국): 앱의 최신 정보 파일 제공. 개인정보는 보내지 않아요.
  • Google Fonts (Google LLC, 미국): 글꼴을 불러올 때 기기의 IP 주소가 전달될 수 있어요.

이 밖의 다른 곳에 개인정보를 넘기거나 팔지 않아요. 광고나 분석 도구도 쓰지 않아요.

4. 기기에 저장하는 것 (쿠키 대신)

추적용 쿠키는 쓰지 않아요. 로그인 상태, 포토카드 수집 수, 직접 넣은 멤버 사진, 닉네임, 글꼴 선택은 이 기기의 브라우저 저장소에만 저장되고 서버로 보내지 않아요(로그인 정보는 로그인할 때만 서버와 주고받아요). 앱을 지우거나 브라우저 데이터를 지우면 함께 사라져요.

Google 글꼴은 처음 열 때 묻고, 허락한 경우에만 불러와요. 언제든 바꿀 수 있어요.

5. 만 14세 미만

만 14세 미만은 회원가입을 할 수 없어요. 가입할 때 만 14세 이상인지 확인해요. 만 14세 미만이 가입한 사실을 알게 되면 계정을 바로 지워요.

6. 내 권리와 삭제 요청

언제든지 소통 탭의 회원 탈퇴 버튼으로 계정과 글을 직접 지울 수 있어요. 내 정보를 보거나 고치고 싶을 때, 또는 탈퇴가 잘 안 될 때는 아래 문의처로 요청해 주세요. 7일 안에 처리할게요.
