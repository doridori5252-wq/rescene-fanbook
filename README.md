# R: 팬노트 (리센느 비공식 팬 앱)

걸그룹 리센느(RESCENE)의 멤버, 디스코그래피, CU 콜라보 빵, 수상 기록을 한곳에 모은 비공식 팬 웹앱입니다.

- `index.html` 파일 하나로 동작해요. 브라우저로 열면 바로 볼 수 있어요.
- GitHub Pages를 켜면 웹 주소로 공유할 수 있어요 (Settings → Pages → Branch: main).
- 빵 체크와 포토카드 수집 개수는 각자 브라우저에만 저장돼요.

정보 기준일: 2026년 11월 5일. 소속사 더뮤즈엔터테인먼트, CU와 관계없는 팬 제작물입니다.
